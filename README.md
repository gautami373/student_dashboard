
# Student Dashboard

A simple and Student Dashboard website created using HTML, CSS, and JavaScript.

## Features
- Sidebar navigation
- Responsive design
- Dashboard cards
- Interactive menu button
- Clean UI

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
├── stddash.html
├── stdstyle.css
├── stdjs.js
└── README.md

## How to Run
1. Download the project files
2. Open `stddash.html` in any browser
